# Bioinformatics Learning Portfolio

## About Me

I am a molecular biologist with a background in biotechnology R&D, specializing in scientific strategy, experimental design, and workflow development.

I am interested in expanding my expertise into bioinformatics and computational biology to strengthen my ability to analyse biological sequences, genomic information and sequencing data.

This repository documents my learning journey, the tools I explore and the practical projects I develop along the way.

## What I Want to Learn

- Biological databases and sequence analysis
- Genome organisation and annotation
- Next-generation sequencing (NGS) data analysis
- CRISPR amplicon sequencing analysis
- RNA sequencing data analysis
- Protein sequence and structure analysis
- Computational approaches to biological research

## Tools I Am Learning

I will gradually learn and use:

- Python and Biopython
- R for bioinformatics applications
- Git and GitHub
- NCBI and Ensembl
- Galaxy
- Linux command line
- Bioinformatics analysis tools and pipelines

## My Projects

I will add projects as I progress through the learning programme.

Each project will include the biological question, data used, analysis methods, scripts, results and my interpretation of the findings.

I will also document the challenges I face and the improvements I make as I learn.

## My Goal

My goal is to develop practical bioinformatics skills and become confident in analysing biological data independently.

I want to build a strong foundation in computational biology and gradually develop the skills needed to work on more complex bioinformatics projects.
